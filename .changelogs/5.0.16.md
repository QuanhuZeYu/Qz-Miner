# Qz-Miner 5.0.16

## 更新

- 修复单人环境下退出世界时，客户端在 `Netty Client IO` 线程直接释放预览 GPU 资源导致的闪退。
- 为客户端预览生命周期清理、客户端状态同步和服务端网络入包统一补上主线程收口，减少网络线程直接触碰世界、状态和生命周期对象带来的竞态风险。
- 新增 `ClientMainThreadDispatcher` 与 `ServerMainThreadDispatcher`，统一客户端与服务端主线程调度入口。
- 将玩家断线清理与单人退主菜单清理切回服务端主线程执行，补强连锁状态与掉落清理的生命周期边界。

## 兼容性与升级动作

- 兼容边界：本版主要围绕线程边界和生命周期清理做稳定性修复，不改变已有功能配置项语义。
- 已知限制：`ClientConnectionListener`、`PlayerManager` 与各网络包处理器的线程收口属于内部实现调整，正常使用方式不变。
- 升级动作：无需手工动作。
