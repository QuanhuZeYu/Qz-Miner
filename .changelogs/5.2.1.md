# Qz-Miner 5.2.1

## 修复

- 修复 `5.2.0` 在 dedicated server 启动时无法应用玩家生命周期 Mixin、导致服务器直接退出的问题。
- vanilla `respawnPlayer` 与 `onDisconnect` 恢复由 refmap 映射到生产 SRG 名；Forge 三参数登录与 Teleporter 跨维度 overload 显式兼容 MCP/SRG selector。

## 兼容性

- 不修改 5.2 已冻结的 packet discriminator/Side、wire、protocol、ordinal、code、mask 或 23-path 配置 schema。
- 完整合法的 `5.2.x` stable、prerelease 与 dev 版本继续按既有 minor-family 策略互通；Qz-UILib 最低版本仍为 `4.6.0`，当前构建使用 `4.6.3:dev`。

- 已依据生产失败日志确认 `respawnPlayer` MCP 名未映射是直接根因；修复后 annotation processor 生成 `respawnPlayer -> func_72368_a` 与 `onDisconnect -> func_147231_a` refmap 条目。
- 本地定向测试、`compileJava`、`test`、`check`、`build` 与 `git diff --check` 已通过，独立只读复核无 P0/P1/P2。
- 修复包的 dedicated server 启动、登录、重生、切维度和断线运行态在发布前仍为 **INCOMPLETE**；CI、refmap 与构建成功不替代该证据。
