# Qz-Miner 5.2.1

## 更新

- 修 `5.2.0` 在 dedicated server 启动时无法应用玩家生命周期 Mixin、导致服务器直接退出的问题。
- vanilla `respawnPlayer` 与 `onDisconnect` 恢复由 refmap 映射到生产 SRG 名；Forge 三参数登录与 Teleporter 跨维度 overload 显式兼容 MCP / SRG selector。

## 兼容性与升级动作

- 兼容边界：不修改 5.2 已冻结的 packet discriminator/Side、wire、protocol、ordinal、code、mask 与 23-path 配置 schema；完整合法的 `5.2.x` stable、prerelease 与 dev 版本继续按既有 minor-family 策略互通。
- 依赖配对：Qz-UILib 最低版本仍为 `4.6.0`，本版构建使用 `4.6.3:dev`。
- 升级动作：无需手工动作。
