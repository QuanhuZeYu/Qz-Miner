# Qz-Miner 5.0.20

## 更新

- 修复 EndlessIDs 扩展方块 ID 导致自动工具换位失效的问题。
- 修复松开连锁键时采样失败导致自动工具事务卡死的问题，使后续连锁轮次能够继续恢复工具。

## 兼容性与升级动作

- 依赖配对：必须安装 Qz-UILib `4.6.0` 或更高兼容版本，本版基于 Qz-UILib `4.6.1`。
- 兼容边界：联机时客户端与服务端必须安装相同版本的 Qz-Miner。
- 升级动作：无需手工动作。
