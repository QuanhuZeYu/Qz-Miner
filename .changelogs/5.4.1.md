# Qz-Miner 5.4.1

## 更新

- **事件总线监听器异常改走日志系统**：`event/EventBus` 隔离单个监听器异常时用 `e.printStackTrace()` 直写 stderr，无前缀、不受日志级别控制、log4j 无法过滤归档。改为 log4j 直连的 `LOG.error`（该类独立于 `MyMod`、可被其他模组直接复用，故不引 `MyMod.LOG`）。

## 兼容性与升级动作

- **事件分发语义逐位不变**：只改异常隔离路径的日志出口，监听器的隔离范围、调用顺序与异常传播规则都不动；`EventBus` 的公共方法与签名不变。
- **依赖配对不变**：仍要求 Qz-UILib `>=4.11.0,<5.0.0`（`required-after:qz_uilib@[4.11.0,5.0.0)`）。
- **联机边界不变**：仍留在 5.3 family，不改 packet / Side、wire / protocol 与 schema 范围。
- **升级动作**：无需手工操作，直接替换 jar。
