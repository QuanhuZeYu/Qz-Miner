# Qz-Miner 5.0.23

## 更新

- 修正自动工具 round 的关闭收口与规划完成发布顺序，避免关闭门残留或执行阶段过早观察到规划完成。
- 修正 GT 线缆兼容 profile，并保持线缆替换的既有安全边界。
- 增加受完整库存与目标身份约束的 round-scoped 空手回退租约，省去稳定批次的逐目标网络等待，同时保留每个目标的服务端实时采掘校验。
- 以通用方块实体 token 冻结 seed 身份，避免规划期间把同方块、不同方块实体误判为同一目标。
- 增加不直接依赖 TiC 的 `HarvestTool` 窄适配，兼容旧式 `null harvestTool` 采掘语义；不放宽非 TiC、显式等级、耐久或执行期权威校验。

## 兼容性与升级动作

- 依赖配对：必须安装 Qz-UILib `4.6.0` 或更高兼容版本，本版基于 Qz-UILib `4.6.1`。
- 兼容边界：联机时客户端与服务端必须安装相同版本的 Qz-Miner。
- 构建基线：支持 GTNH `2.8.4` 与 `2.9.0-beta-2`，默认出包基线 `2.9.0-beta-2`。
- 升级动作：无需手工动作。
