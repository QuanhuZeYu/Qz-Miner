# Qz-Miner 5.3.0

## 更新

- 网络兼容族升至 5.3 并冻结：17 个 packet discriminator/Side、20-path 配置 schema、wire 合同 52→53；`5.2.x` 及更旧端在握手期 fail-closed 拒绝，混合双端需同步升级。
- 以共享 soft deadline 取代预算与节流模型：`tickBudgetMs`（1..40ms）统一约束 planning / preview / 普通执行；移除 work-unit 计费、空气 1024:1 补偿、`maxBreakPerTick` 与 50ms 节流。5.2 的 YAML / cfg 预算键自动迁移；watchdog 增加 ExecutionDeferred 有界宽限。
- 预览渲染管线重构：`ChainPreviewRenderCache` 按代际发布 mesh，Renderer 注入 previewState，MeshBuilder 拆分构建职责，State 改代际 API。
- 并行遍历样板收敛与选择器接线去重复：PlanningCandidateGate 共享映射覆盖 6 个 traverser 与 ChainSearchAlgorithm；picker 候选索引共享、VisualAdapter 懒建。
- 方块选择器接入与联动：空查询返回全量浏览快照供分类浏览；接入全屏面板（创造栏 / Mod 双分类、中文文案、搜索增强）；成员网格重设计（多列卡片加可见滚动条），成员删除一步直达。
- 使用文档与网络版本边界文档同步更新。

## 兼容性与升级动作

- 兼容边界：5.3 为冻结兼容族，5.2 及更旧端 fail-closed 拒绝；同 5.3 minor 的 patch / prerelease / dev 互通。
- 依赖配对：Qz-UILib 为硬依赖，运行时最低 4.8.0，本版编译配对 4.8.0（dev 制品经仓库 libs 目录解析，不走 JitPack）；发布包不内嵌，由整合包提供。
- 升级动作：配置 schema 收为 20 路径，5.2 的预算键自动迁移，无需手工改写配置。

## 验证边界

- 已验证：本机完整 build（编译、checkstyle、全量 JUnit、assemble）通过。
- 未验证：运行态（网络 5.3 双端握手、fail-closed 边界、预览渲染、选择器面板等）以用户真机验证为准，发布前尚未完成全量运行态验收。
