# Qz-Miner 5.1.0

## 本次更新

- 自动工具换位协议升级为 v4：接替请求使用独立、发布即烧号的 `takeoverRequestId`，库存 mutation
  只提交一次，完整库存 publication 与动作回执可按同一请求精确重试；目标局部失败只跳当前目标。
- 方块身份统一覆盖完整 signed `int` 合同：存在目标的 block ID 为 `1..Integer.MAX_VALUE`，metadata
  为 `0..Integer.MAX_VALUE`，block ID `0` 保留为空气/缺席 sentinel；对象组 selector 同步覆盖完整非负 int 域。
- 服务端规划与客户端预览统一采用 context 级 1024:1 空气候选预算；CHAIN 按冻结工具能力断链，AREA
  保持空间范围宽进并由服务端主线程逐目标终裁。
- `INTERACT` 接通同类方块、液体源、全部作物、未成熟作物施肥四种完整立方范围交互；BLOCK/AIR
  统一进入宽泛右键入口，执行前继续逐目标重验世界、权限、冻结身份和当前手持物。

## 5.1 兼容合同

- 客户端与服务端只要都提供完整合法的 `5.1.x[-prerelease][+build]` 版本，即忽略 patch 与 qualifier
  互通；stable、prerelease、branch/dirty dev 均适用。`5.0.x`、`5.10.x` 与畸形版本明确拒绝。
- 5.1 family 冻结当前 16 个 packet discriminator/Side、协议版本、字段顺序、framing、ordinal、wire
  code、对象组 mode bit 与 24-path 配置 schema。不兼容变化必须升级到新的 minor family。
- 远端版本表缺少 `qz_miner` 时 Forge checker 在 CLIENT/SERVER 两侧均放行，但这只放宽 mod-list
  检查，不保证无 Qz-Miner 对端拥有网络 channel 或业务运行安全。
