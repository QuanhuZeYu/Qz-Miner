# Qz-Miner 5.4.0

## 更新

- **GTNH 2.8.0 / 2.8.4 纳入运行期兼容范围**：同一份 jar 现在承诺覆盖 `2.8.0`、`2.8.4`、`2.9.0-beta-2`、`2.9.0-beta-3` 四个基线，构建基线仍是 `2.9.0-beta-3`。
- **修 BW 普通矿的时运开关失效**：`bartworks.system.material.BWTileEntityMetaGeneratedOre` 的字段名此前写成 `natural`，实际是 `mNatural`，使 `enableFortuneForPlacedOre` 与 `enableUnlimitedOreFortune` 对该类矿石完全不生效。该类只在 2.8.x 世代存在，所以这个失效只在 2.8.x 上可复现。

## 兼容性与升级动作

- **矿石入口按宿主世代自动分派**：2.8.x 与 2.9.x 的普通矿是两套类，各自独立适配，在四个基线之间切换不需要改任何配置。
- **时运开关的覆盖范围**：`enableFortuneForPlacedOre` 与 `enableUnlimitedOreFortune` 在四个基线上均覆盖 GT / BW / GT++ 的普通矿；其中 BW 那一支自本版起才真正生效。
- **依赖配对不变**：仍要求 Qz-UILib `>=4.11.0,<5.0.0`（`required-after:qz_uilib@[4.11.0,5.0.0)`）。
- **联机边界不变**：仍留在 5.3 family，不改 packet / Side、wire / protocol 与 schema 范围。
- **升级动作**：无需手工操作，直接替换 jar；整合包与服务器仍应与 Qz-UILib 4.11.x 配对。
