# Qz-Miner 5.3.2

> **已定档 `5.3.2`（小版本 / patch）**。依据同 `5.3.1`：Miner 的版本 family 就是网络兼容 family——
> `QzMinerNetworkVersionPolicy.isCompatibleFamily` 只接受完整的 `5.3.x` family（5.3.x 全组合互通），
> 本轮**不改协议 / wire**（改动集中在客户端连锁预览渲染、配置面与方块选择器内部实现），
> 留在 5.3 family 才能保持与 `5.3.0` / `5.3.1` 联机互通；`5.4.x` 仍留给协议 / wire 变化。
>
> 随定档同步：开发默认版本由 `5.3.1-dev` 升为 **`5.3.2-dev`**（`build.gradle.kts` 第 23 行）。
> 本文件覆盖 `5.3.1` tag 之后的全部提交（170 个）。

## 更新

### 连锁预览（本轮主体；客户端）
- **着色器主路径落地**：新增 GLSL 主路径（`preview.vert` / `preview.frag`），任何失败必回退 legacy；
  后端档位 `auto` 可在运行时落到着色器路径。
- **显式相机矩阵**：修复 Angelica（GLSM 模拟固定管线）+ `use_no_error_g_l_context=true` 环境下内建
  `gl_ModelViewProjectionMatrix` 与真实相机矩阵**失同步**（表现为整条预览被画进错误空间、紧凑一束条柱），
  改为显式 uniform 上传 + 后端自检 + 一次性诊断后回退。
- **属性绑定修复**：属性槽位改运行时解析——此前假设 `aPos` 在槽位 0，真机实际在槽位 1，顶点坐标一直从 ABO 字节读。
- **顶点流改造（T51）**：顶点按面分裂；`aDirection` 由 float×3 改为 4×int8 归一化（顶点流省 8.25 MB/mesh）；
  移除已完成使命的 `aColor` 顶点流与 CBO（颜色改由 `aAux.semanticClass` + uniform 调色板在顶点阶段决定）。
- **视觉能力**：真描边（OUTLINE 档沿面法线外扩）、屏幕最小宽度钳制、逐波生长动画、距离淡出、
  面朝向明暗、连锁序渐弱；其中**描边与最小宽度共用同一份世界空间位移预算**（最小宽度优先、描边让位，
  联合位移恒不越出自身方块）。
- **深度档**：xray / occlude / outline 三档；OUTLINE 档壳段先画、主体后画。
- **LOD 自动档**：构建期按方块中心 alpha 剔除远处散点目标，enter / exit 双阈值防抖。
- **有界容量与峰值**：4096 目标硬上限，超限走既有 truncated 语义（网格与会话同时可见），不计静默截断。
- **代级增量**：26 邻域可见段增量缓存 + 稳定锚点 + 差分基线 + 分片续跑，同代刷新不再整份重建。
- **修**：OUTLINE 档描边宽度配 0 时同一几何走两趟、混合两次（"0 = 关闭"实际是加重叠色）⇒ 收敛为单遍。

### 连锁预览配置面
- 新增「连锁预览观感档位」配置组（B0.1）。
- **语义颜色按大模式区分（六色调色板）**：CHAIN `0x40E6FF` / AREA `0xE8503C` / INTERACT `0x58E07A` /
  SUB_MODE `0xB08CFF` / REMOTE `0x8FA9D0` / TRUNCATED `0xF8C858`；类别 id 见 `ChainPreviewSemanticClass`。
- **颜色字段改用 Qz-UILib `ColorSpec`**：支持 `#RRGGBB` / `0xRRGGBB` / 十进制输入（编辑期小数点转换），
  本仓私有 HEX 实现已删除，只保留 UILib 通用能力。
- **连锁序渐弱**：新增 `clientPreviewOrderMinBrightness`（默认 0.55）——按条柱在预览集合里的出现序号线性降低
  **颜色亮度**；与「距离淡出」解耦（两者此前会抢同一个 alpha），最终 alpha 只由 距离淡出 × 逐波生长 × 淡入包络 决定。
- **内部结构亮度**：新增 `clientPreviewInteriorDim`（默认 0.65，1.0 = 关闭）——把"内部结构"（非贯通管面，
  即 junction 补块 / 共享顶点）的颜色亮度压暗，用于"外轮廓强、内部格线弱"。
- **面朝向明暗默认开启**（`clientPreviewFaceShading`，与 legacy 颜色流同表、同判定顺序）。
- 配置项 label 中文化（本轮使用不依赖 UILib 通道的本地化代理实现）。
- **兼容说明**：颜色类配置与上述两项亮度系数**只对着色器后端生效**（legacy 恒用 CPU 常量色）；
  新增 / 变更的默认色**不会自动迁移**旧 `.cfg` 里的已存储值——需把对应键恢复默认才能看到新默认色。

### 方块选择器
- Provider 收敛：候选源改惰性接线，删除构造期全量枚举与每次查询的全量预转换。
- 清单快照 / 分片物化 / 有界分片缓存：构造期枚举与物化解耦。
- 注册表失效接入：FML 事件标脏 + 20 tick 兜底。
- 删除过渡态 `BlockVariantEnumerator`；选择器图标改由候选域键供给。
- 修：搜索窗口上限、标签可读性、分类筛选与 hover 质感。

### 对象组编辑器
- 字段改为摘要卡 + 专用全屏编辑视图（含成员编辑态接线）。
- 修左栏交互：整卡命中 / roving Tab / 键盘导航 / ESC 两段式 / 重命名身份保持。
- 修真机可用性缺陷：模式可选性、左栏拥挤、背板穿透、窄挡下钻。
- 默认配置改为「红石矿石」单组，并保证「恢复默认」生效。

### 稳定性修复
- 修客户端启动崩溃：FML 生命周期事件误用 `@SubscribeEvent`（改走 `@Mod.EventHandler` → `SidedProxy` 转发）。
- 修方向 staging 使用 heap `ByteBuffer` 导致的真机驱动崩溃。
- 修 LOD 滞回清理的无锁集合竞态（改主线程置位、构建线程消费）。
- 修 GL 上下文失效逃逸（后端封装统一 GL 围栏）与上传路径的 GL 状态串扰（Angelica GLSM 状态缓存）。

### 工程与测试
- 移除着色器 / Java 源面的**源码文本断言**（不检验行为、改动必红），改为真机验证记录标记 + 行为化断言。
- 新增 **GLSL 离线校验闸门**（glslang 逐文件编译，挂在 `test` / `check` 之前）与**固定管线内建禁令**
  检查（按完整标识符判定 + 词法级负例）。
- 测试基础设施：GLSL / JSON / lang 扫描入口统一，`CompiledClasses` 支持注解元素与指令级读取。
