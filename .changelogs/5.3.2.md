# Qz-Miner 5.3.2

**本版要点**

- 连锁预览改走 GLSL 主路径（任何失败回退 legacy），修 Angelica 环境下预览被画进错误空间、顶点属性槽位错读与 OUTLINE 描边叠加成色。
- 配置面新增「连锁预览观感档位」组：六色语义调色板、连锁序渐弱、内部结构压暗、面朝向明暗默认开启；颜色字段改用 Qz-UILib 4.10.0 的 `ColorSpec` 族。
- 方块选择器候选源改惰性接线；对象组编辑器出厂默认修复为「红石矿石」单组（#251、#183）。
- 稳定性：修客户端启动崩溃、方向 staging 的 heap `ByteBuffer` 驱动崩溃、LOD 清理解竞态与 GL 上下文失效逃逸。

## 兼容性与升级动作

- **依赖配对（必须成对升级）**：本版编译与运行配对 Qz-UILib **4.10.0**，依赖下界由 `[4.9.1,5.0.0)` 抬到 `required-after:qz_uilib@[4.10.0,5.0.0)`。下界必须抬的理由是本版颜色字段用了 4.10.0 才提供的 `ColorSpec` 族；与 4.9.x 混用时 Forge 依赖检查会放行，随后在类加载期 `NoClassDefFoundError`（与历史 issue #73 同形态）。
- **上游公共面收缩**：Qz-UILib 4.10.0 相对 4.9.1 有 8 项公共面删除——`SearchResultList$Row`、`SearchPickerPresentation.currentMember`、`ItemRenderFallbackKeys.splitRegistryKey`、`SearchPickerSpec.maxItems()` 与其两个 int 构造器、`Values.searchPicker(id,int[,mode])`。用到这些符号的下游需按 4.10.0 迁移指引各自改造，本仓已改完。
- **联机边界不变**：仍留在 5.3 family，`5.3.x` 全组合互通（`QzMinerNetworkVersionPolicy.isCompatibleFamily`）；本版不改 packet / Side、wire / protocol 与 schema 范围。
- **升级动作**：整合包与服务器需把 Qz-UILib 一起升到 4.10.0。`client.objectGroups` 没有自动迁移——旧版保存过的默认组（空 `modes`）会原样保留，升级后需在配置页对该字段点一次「恢复默认」，或自行给组补上四个模式。
- **已知限制**：颜色类配置与两项亮度系数只对着色器后端生效（legacy 恒用 CPU 常量色）；新增 / 变更的默认色不自动迁移旧 `.cfg` 值。

### 连锁预览（客户端）

- 着色器主路径落地：新增 GLSL 主路径（`preview.vert` / `preview.frag`），任何失败都回退 legacy；后端档位 `auto` 可在运行时落到着色器路径。
- 修 Angelica（GLSM 模拟固定管线）配 `use_no_error_g_l_context=true` 时内建 `gl_ModelViewProjectionMatrix` 与真实相机矩阵失同步的问题：症状是整条预览被画进错误空间、缩成一束紧凑条柱；现改为显式 uniform 上传加后端自检，诊断一次后回退。
- 修顶点属性槽位：属性槽位改运行时解析。此前假设 `aPos` 在槽位 0，真机实际在槽位 1，顶点坐标一直从 `ABO` 字节读。
- 顶点流改造：顶点按面分裂；`aDirection` 由 float×3 改为 4×int8 归一化，顶点流省 8.25 MB/mesh；移除已完成使命的 `aColor` 顶点流与 `CBO`，颜色改由 `aAux.semanticClass` 加 uniform 调色板在顶点阶段决定。
- 视觉能力：真描边（OUTLINE 档沿面法线外扩）、屏幕最小宽度钳制、逐波生长动画、距离淡出、面朝向明暗、连锁序渐弱。描边与最小宽度共用同一份世界空间位移预算——最小宽度优先、描边让位，联合位移恒不越出自身方块。
- 深度档：xray / occlude / outline 三档；OUTLINE 档壳段先画、主体后画。
- LOD 自动档：构建期按方块中心 alpha 剔除远处散点目标，enter / exit 双阈值防抖。
- 有界容量：4096 目标硬上限，超限走既有 truncated 语义（网格与会话同时可见），不计静默截断。
- 代级增量：26 邻域可见段增量缓存加稳定锚点、差分基线与分片续跑，同代刷新不再整份重建。
- 修 OUTLINE 档描边宽度配 0 时同一几何走两趟、混合两次（「0 = 关闭」实际成了加重叠色），收敛为单遍。

### 连锁预览配置面

- 新增「连锁预览观感档位」配置组。
- 语义颜色按大模式区分（六色调色板）：CHAIN `0x40E6FF` / AREA `0xE8503C` / INTERACT `0x58E07A` / SUB_MODE `0xB08CFF` / REMOTE `0x8FA9D0` / TRUNCATED `0xF8C858`；类别 id 见 `ChainPreviewSemanticClass`。
- 颜色字段改用 Qz-UILib 4.10.0 的 `ColorSpec` 族（`config.schema.ColorSpec` / `HexColorCodec` / `config.ui.field.ColorFieldRenderer`）：支持 `#RRGGBB` / `0xRRGGBB` / 十进制输入，编辑期保留未完成原文；本仓私有 HEX 实现已删除。
- 新增 `clientPreviewOrderMinBrightness`（默认 0.55）：按条柱在预览集合里的出现序号线性降低颜色亮度，与距离淡出解耦。
- 新增 `clientPreviewInteriorDim`（默认 0.65，1.0 = 关闭）：压暗内部结构（非贯通管面，即 junction 补块与共享顶点）的颜色亮度，用于「外轮廓强、内部格线弱」。
- `clientPreviewFaceShading` 面朝向明暗默认开启，与 legacy 颜色流同表、同判定顺序。
- 最终 alpha 只由 距离淡出 × 逐波生长 × 淡入包络 决定。
- 配置项 label 中文化。
- 兼容提醒：颜色类配置与上述两项亮度系数只对着色器后端生效（legacy 恒用 CPU 常量色）；新增 / 变更的默认色不会自动迁移旧 `.cfg` 里的已存储值，需把对应键恢复默认才能看到新默认色。

### 方块选择器

- 候选源改惰性接线，删除构造期全量枚举与每次查询的全量预转换。
- 清单快照、分片物化与有界分片缓存：构造期枚举与物化解耦。
- 注册表失效接入：FML 事件标脏加 20 tick 兜底。
- 删除过渡态 `BlockVariantEnumerator`；选择器图标改由候选域键供给。
- 修搜索窗口上限、标签可读性、分类筛选与 hover 质感。

### 对象组编辑器

- 字段改为摘要卡加专用全屏编辑视图（含成员编辑态接线）。
- 修左栏交互：整卡命中、roving Tab、键盘导航、ESC 两段式、重命名身份保持。
- 修真机可用性缺陷：模式可选性、左栏拥挤、背板穿透、窄挡下钻。
- 出厂默认对象组改为「红石矿石」单组，并保证「恢复默认」生效（修 #251，#183 同因）。此前默认组 `modes` 为空列表，`ObjectGroupMode.toMask(空) = 0` 使对象组规则集直接返回空扩展，红石组从未参与匹配，成员也漏了 EFR 的深板岩红石矿石。现默认组显式声明 4 个模式（`chain_base` / `chain_ore` / `area_same_block` / `area_ore`）与 4 条成员（`minecraft:redstone_ore@*` / `minecraft:lit_redstone_ore@*` / `etfuturum:deepslate_redstone_ore@*` / `etfuturum:deepslate_lit_redstone_ore@*`），默认值唯一真源收敛到 `QzMinerConfigDefaults.objectGroups()`。

### 稳定性修复

- 修客户端启动崩溃：FML 生命周期事件误用 `@SubscribeEvent`，改走 `@Mod.EventHandler` 加 `SidedProxy` 转发。
- 修方向 staging 使用 heap `ByteBuffer` 导致的真机驱动崩溃。
- 修 LOD 滞回清理的无锁集合竞态：改主线程置位、构建线程消费。
- 修 GL 上下文失效逃逸（后端封装统一 GL 围栏）与上传路径的 GL 状态串扰（Angelica GLSM 状态缓存）。
