# Qz-Miner 5.2.0

## 更新

- 新增 `AREA_CUBOID_CLEAR` 框选清空模式：未按连锁键时用左键、右键设置两个端点，按连锁键后从框内或框外触发清空；客户端常驻显示选区 AABB，服务端按已接受的 `chainMaxBlocks` 权威校验体积。
- 新增权限等级 4 的 `/qzminer config list|get|set|reload`，用于受限查看和热修改 `general.*` scalar 配置；提交失败不会改写当前配置或运行态。
- 自动工具换位完全收口到服务端本地主线程批处理，不再依赖客户端库存扫描、逐目标 takeover 请求或旧服 fallback。
- 玩家连锁实例改由 vanilla 登录、重生、跨维度和断开边界创建、更新与销毁；客户端在服务端 endpoint ready 后按连接代际单次恢复当前模式和配置，修复退出世界后进入新世界时框选模式失效。

## 兼容性与升级动作

- 兼容边界：5.2 使用严格 minor-family 握手，完整合法的 `5.2.x` stable、prerelease 与 dev 版本忽略 patch 和 qualifier 后互通；5.0、5.1、5.10 与畸形版本拒绝连接。5.2 固定 17 个 packet discriminator/Side、现有 wire / protocol / ordinal / code / mask 与 23-path 配置 schema，不提供跨 minor fallback。
- 依赖配对：Qz-UILib 为硬依赖，最低版本 `4.6.0`，本版构建使用 `4.6.3:dev`。
- 升级动作：无需手工动作。

## 验证边界

- 已验证：本地 `test`、`check`、`build` 通过；本次问题对应的「退出世界后进入新世界」场景已经用户实机复测，未发现异常。
- 未验证：其余运行态未覆盖。
