# Qz-Miner 5.2.0

## 本次更新

- 新增 `AREA_CUBOID_CLEAR` 框选清空模式：未按连锁键时用左键、右键设置两个端点，按连锁键后从框内或框外触发清空；客户端常驻显示选区 AABB，服务端按已接受的 `chainMaxBlocks` 权威校验体积。
- 新增权限等级 4 的 `/qzminer config list|get|set|reload`，用于受限查看和热修改 `general.*` scalar 配置；提交失败不会改写当前配置或运行态。
- 自动工具换位完全收口到服务端本地主线程批处理，不再依赖客户端库存扫描、逐目标 takeover 请求或旧服 fallback。
- 玩家连锁实例改由 vanilla 登录、重生、跨维度和断开边界创建、更新与销毁；客户端在服务端 endpoint ready 后按连接代际单次恢复当前模式和配置，修复退出世界后进入新世界时框选模式失效。

## 兼容性

- 5.2 使用严格 minor-family 握手：完整合法的 `5.2.x` stable、prerelease 与 dev 版本忽略 patch 和 qualifier 后互通；5.0、5.1、5.10 与畸形版本拒绝连接。
- 5.2 固定 17 个 packet discriminator/Side、现有 wire/protocol/ordinal/code/mask 与 23-path 配置 schema；不提供跨 minor fallback。
- Qz-UILib 仍为硬依赖，最低版本 `4.6.0`；当前构建使用 `4.6.3:dev`。

## 验证边界

- 本地 `test`、`check`、`build` 与 `git diff --check` 已通过；生命周期修复经过两轮只读代码审查，无 P0/P1/P2 阻断项。
- 本次问题对应的退出世界后进入新世界场景已由用户实机复测，未发现异常。
- 发布候选 exact-SHA 的双 GTNH baseline branch CI、tag workflow、GitHub Release 与 assets 将按各自不可变身份独立核验；本正文不替代这些发布证据。
