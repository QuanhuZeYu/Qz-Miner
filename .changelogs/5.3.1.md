# Qz-Miner 5.3.1

**本版要点**

- HUD 接入改用 Qz-UILib 4.9 的虚拟窗口契约（`HudWindowFactory` / `HudLayoutService`），业务侧由 `QzMinerHudModel`、`QzMinerHudWindow`、`QzMinerHudTicker` 承担，内容集合、行序与左上角锚点等使用者可见行为不变。
- HUD 外观改为液态玻璃卡片，配方由主题 `SceneTheme.Role.PANEL` 派生（tint、边框、圆角随主题），并关闭宿主外壳以免双层底色。
- 新增聊天工具栏「编辑 HUD」入口与可编辑 HUD 目标，预览卡片可命中拖动；关闭态 HUD 不再挂常驻工具栏或缩放 UI，缩放只在编辑子模式里由 UILib 编辑层提供。
- 新增 HUD 布局与缩放持久化：`MinerHudLayoutStore` 把布局落盘 `config/qz_miner-hud-layout.txt`，文本格式、`schemaVersion` 判定与锚点百分比换算全部归 UILib，Miner 不解析内容也不做坐标数学。
- GTNH 基线升至 `2.9.0-beta-3`、真源收敛为 `dependencies.gradle` 单值声明，多基线构建机制退役、构建按单一基线运行。

## 兼容性与升级动作

- 兼容边界：网络协议不变，仍是 5.3 冻结族（17 个 packet discriminator/Side、20-path 配置 schema、wire 合同 53）；`5.3.x` 全组合互通，`5.4.x` 留给协议 / wire 变化。
- 依赖配对：需与 Qz-UILib **4.9.1** 成对升级，依赖下界 `required-after:qz_uilib@[4.9.1,5.0.0)`。理由是公开 HUD 编辑契约（`HudEditTarget` / `HudEditService` / `ChatActionService`）自 4.9.1 起提供；留在 4.9.0 会被 Forge 依赖检查放行，随后在类加载期 `NoClassDefFoundError`。4.9.1 相对 4.9.0 是纯增量，UILib 的远端混用面为 `[4.9.0,4.10.0)`，两者可双端混用，但本 Mod 的运行下界以 4.9.1 为准。
- 同版本内容漂移：本版还用到 `HudLayoutStore` / `HudLayoutPersistence`，它们只存在于 4.9.1 的最新交接件里。同名同版本号的更早 4.9.1 件不含这两个类，混用同样在类加载期 `NoClassDefFoundError`；构建期制品守卫只按 `mcmod.info` 的版本区间判定，识别不了这种漂移，集成与发布请以 Release 页登记的制品哈希为准。
- 升级动作：整合包需把 Qz-UILib 一起升到 4.9.1。用到旧快照族（`CompactHud` / `HudSnapshotProvider` / `HudLine` / `HudSnapshot` / `HudSpan` / `HudTone` / `TextHud`）的下游需删除私有实现，改用 `HudWindowFactory` 族。
- 已知限制：同 jar 兼容范围含 GTNH `2.9.0-beta-2` 与 `2.9.0-beta-3`，依据是源码对 GTNH 侧组件零静态链接；`2.8.4` 不在承诺内，双基线结论改为人工编译流程（`-P` 覆盖通道已失效）。HUD 位置只落「四角锚点 + 该轴行程百分比」，不落绝对坐标；未安装持久化端口或宿主不上报度量时，行为与旧版逐位一致（零 IO、不改偏移、不切锚点）；无法识别的数据或未知 `schemaVersion` 会降级为默认布局，且本次会话不写回、不覆写用户原文。

### HUD 迁移到 Qz-UILib 虚拟窗口契约

- HUD 接入改用 Qz-UILib 4.9 的虚拟窗口契约：删除旧的 `ui.hud.api` 快照族（`CompactHud` / `HudSnapshotProvider` / `HudLine` / `HudSnapshot` / `HudSpan` / `HudTone` / `TextHud`）与 Miner 侧 `QzMinerHudSnapshotProvider`，改为 `HudWindowFactory` / `HudLayoutService`，业务侧由 `QzMinerHudModel`（业务状态 → 不可变语义模型）、`QzMinerHudWindow`、`QzMinerHudTicker` 承担。
- 注册仍是 `ClientProxy.init` 单点 `ClientHudService.register(HudSpec("qz_miner:chain-status", HudAnchor.TOP_LEFT), factory)`，断线不重注册、不 close。
- 使用者可见行为不变：内容集合与行序不变，锚点仍在左上角，窗口显隐仍由 UILib 宿主负责；空模型 → 内容根零尺寸 → 宿主整窗隐藏（对齐旧 EMPTY 快照）；色调 `Tone.{MUTED,INFO,SUCCESS,WARNING}` 映射 `SceneChromeTokens.HUD_TEXT_*`，HUD 文本不含样式编码。
- 外观改为液态玻璃卡片：`UiBackdrop.liquidGlass(UiGlassMaterial.DARK_THIN, 10, 0.60F)` 配 `SceneSurfaceBinder.bind`，配方由主题 `SceneTheme.Role.PANEL` 派生（只钉死滤镜参数，tint / 边框 / 圆角随主题）；`HudSpec.chrome(false)` 关闭宿主外壳，避免「宿主半透明外壳 + 卡片玻璃」双层底色。

### 编辑入口与缩放收敛

- 新增聊天工具栏「编辑 HUD」入口与可编辑 HUD 目标：可编辑目标经 `HudEditService.register(HudEditTarget.builder(HUD_ID)...)` 注册，注册单点 `QzMinerHudEditEntry.install`（由 `ClientProxy.init` 调用），以 UILib 注册表实际内容判幂等、逐件异常隔离、句柄常驻；聊天动作 `ChatActionService.register(ChatAction.builder("qz_miner:hud_edit"))`，label / tooltip 走 `ClientI18n`（`hud.qz_miner.edit_action.label/tooltip`，中英齐全），无活动聊天屏时由 UILib 静默丢弃。
- 预览根可命中：UILib 编辑宿主把拖动 handler 挂在预览内容根上，而 HUD 内容根恒不可命中（关闭态不得拦截游戏输入），预览工厂因此另包一层可命中的拖动命中面，内部卡片与文本仍不可命中。
- 预览不跟随显示门：编辑会话在聊天输入屏里连锁键必然松开，`QzMinerHudModel.translateForPreview` 给出当前设置下的完整卡片内容，否则预览零尺寸无法拖动；`translate` 的显示门语义不变，预览卡片的默认放置与 `HudSpec.margin` 共用 `QzMinerHudWindow.HUD_MARGIN_PX`。
- 关闭态 HUD 不再挂任何常驻工具栏或缩放 UI：删除 `ClientProxy` 里的 `HudToolbarService` 注册、注册句柄字段与 `QzMinerHudWindow.TOOLBAR_FACTORY`。缩放只在聊天屏「编辑 HUD」子模式里由 UILib 编辑层在预览旁提供 `- / 1:1 / +`；Miner 不自绘缩放与编辑 UI、不持倍率状态，生产源码也不得调用常驻工具栏 API。

### HUD 布局与缩放持久化

- 新增 `MinerHudLayoutStore`，实现 UILib 的纯文本端口 `HudLayoutStore`（`String load()` / `void save(String)`）：整串读、整串原子写，写路径复用 UILib `AtomicFileWrites.writeUtf8Atomically`；文件缺失或 IO 异常时 `load()` 返回空串，读写异常一律只记日志、不外溢。落盘 `config/qz_miner-hud-layout.txt`。
- 文本格式、`schemaVersion` 判定、锚点与百分比换算全部归 UILib；Miner 不解析内容、不做坐标数学，也不引用布局与缩放类型。
- `ClientProxy` 在编辑入口之后接线 `HudLayoutPersistence.install(...)`。写盘由 UILib 在编辑提交与缩放变更合并后触发，Miner 不做定时或退出落盘。

### 构建与交付

- GTNH 基线升至 `2.9.0-beta-3`，真源收敛为 `dependencies.gradle` 的 `elytraModpackVersion` 单值声明；`gradle.properties` 不再声明 `elytra.manifest.*`。
- 多基线构建机制退役：删除 `gradle/gtnh-baselines.json`、`scripts/verify-gtnh-baselines.ps1` 与 `verifyGtnhBaseline` 任务，构建按单一基线运行。
