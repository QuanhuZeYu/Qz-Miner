## 本次更新

- 重构 GT 线缆替换与增量壳扫流程，补齐会话状态、连通遍历与兼容适配层的稳定性改造。
- 修复网络入包防御与客户端预览生命周期清理，补强预览相关的连接切换与异常路径处理。
- 整理 AI 协作文档框架、错误索引与分支管理规范，补齐 `docs/README.md`、`docs/记忆/`、`docs/开发者文档/` 三层文档入口。
- 修复 `enableUnlimitedOreFortune` 对 GT / BW / GT++ 普通矿无效的问题。
- 将矿石时运上限突破实现从重定向 `Random.nextInt(...)` 改为拦截上游 `fortune > 3` 表达式，确保高等级时运不再被提前截断到 3 级。
- 为 release workflow 增加标准化说明，后续版本可通过 `.changelogs/<tag>.md` 覆盖 GitHub 自动生成的发布内容。

## 兼容性说明

- 本版本实际发布范围包含 `5.0.14` 之后主线尚未推送到远端的改动，不仅限于时运上限修复。
- `enableUnlimitedOreFortune` 关闭时，仍保持原版时运上限逻辑。
- `enableFortuneForPlacedOre` 的原有语义未变，放置矿是否享受时运仍由该配置控制。
- `mixins.qz_miner.json` 已声明 `mixinextras.minVersion = 0.5.0`，以匹配当前时运上限修复的表达式注入实现。
