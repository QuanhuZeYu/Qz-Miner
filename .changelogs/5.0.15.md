# Qz-Miner 5.0.15

## 更新

- 重构 GT 线缆替换与增量壳扫流程，补齐会话状态、连通遍历与兼容适配层的稳定性改造。
- 修复网络入包防御与客户端预览生命周期清理，补强预览相关的连接切换与异常路径处理。
- 修复 `enableUnlimitedOreFortune` 对 GT / BW / GT++ 普通矿无效的问题。
- 将矿石时运上限突破实现从重定向 `Random.nextInt(...)` 改为拦截上游 `fortune > 3` 表达式，确保高等级时运不再被提前截断到 3 级。
- release workflow 支持通过 `.changelogs/<tag>.md` 覆盖 GitHub 自动生成的发布内容。

## 兼容性与升级动作

- 兼容边界：本版实际发布范围包含 `5.0.14` 之后主线尚未推送到远端的改动，不限于时运上限修复。
- `enableUnlimitedOreFortune` 关闭时仍保持原版时运上限逻辑；`enableFortuneForPlacedOre` 的原有语义未变，放置矿是否享受时运仍由该配置控制。
- `mixins.qz_miner.json` 已声明 `mixinextras.minVersion = 0.5.0`，以匹配当前时运上限修复的表达式注入实现。
- 升级动作：无需手工动作。

## 验证边界

- 已验证：`./gradlew.bat compileJava` 通过（本地编译级）。
- 未验证：运行态未验证。
