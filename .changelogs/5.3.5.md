# Qz-Miner 5.3.5

## 更新

- 编译与运行配对件升到 Qz-UILib **4.11.0**：`@Mod` 依赖下界由 `[4.10.0,5.0.0)` 抬到 `[4.11.0,5.0.0)`，本地配对件同步换成上游 Release 资产。
- 按 4.11.0 的公共面签名变更接入环境端口：候选源版本桥与图标解析器改为从场景运行时读取宿主环境（旧签名已在上游删除）。
- 本版不含玩法改动：packet / Side、wire / protocol、schema、配置路径与 canonical 字符串均未改动。

## 兼容性与升级动作

- **依赖配对（必须成对升级）**：本版编译与运行配对 Qz-UILib 4.11.0。下界必须抬的理由是 4.11.0 删除了 `PickerRevisionBridge.forSource(source)`、`PickerIconResolver.of(provider)` 与 `SceneRuntime(SceneTextMeasurer)` 三个签名，且上游已把自身远端范围收紧为 `[4.11.0,4.12.0)`——4.11.0 与 4.10.x 双向不承诺混用。若仍声明 `[4.10.0,5.0.0)`，Forge 依赖检查会放行 4.11.0，随后在打开对象组编辑器时以 `NoSuchMethodError` 失败。
- **升级动作**：整合包与服务器把 Qz-UILib 一并升到 4.11.x；无需手工改配置或迁移数据。
- **随上游一并生效的可见变化**：4.11.0 在每个客户端 tick 守卫下停用 Angelica 的 HUD 缓存，连锁状态 HUD 的液态玻璃卡片恢复半透明；代价是 HUD 由缓存复用改为每帧重绘。
- **构建基线与联机边界不变**：GTNH 单基线仍为 `2.9.0-beta-3`，运行期兼容范围仍为 `2.9.0-beta-2` / `2.9.0-beta-3`，`2.8.x` 不在本版承诺内；5.3 family 内客户端 / 服务端依旧忽略 patch 与 qualifier 互通。
