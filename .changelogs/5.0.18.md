## 本次更新

- 适配 GTNH `2.9.0-beta-1` 开发依赖基线。
- Qz-UILib 升级到 `4.6.0`，开发环境使用 `dev` classifier，并接入 DraftValidator 在写盘前拒绝非法草稿。
- 配置权威迁至 `config/qz_miner.yaml`：增加 raw NodeType preflight，空 YAML 按 schema 缺字段使用默认值，旧 cfg 仅作一次性导入源。
- 删除旧 Forge config dead API 与降级配置页，运行时只保留 UILib ConfigManager + current validated snapshot 单向派生发布。
- 对象组成员启用 UILib `LIST_MEMBERS` 管理选择器：配置行常驻规则摘要与管理入口，raw 默认折叠为高级编辑；portal 采用受约束宽高、顶部搜索和当前规则/搜索结果 3:5 动态分区。编辑按稳定 ID 单项替换，删除需二次确认，新增追加且重复 registry 只提示不合并；常规界面不显示 malformed 原文，高级 raw 仍无损保留，合法未知项继续显示 canonical。
- 修复 GT / BW / GT++ 普通矿在 GTNH 2.9 adapter 入口下的高等级时运适配。
- 适配 GT 线缆刷新 API 变化，保持线缆替换后的显示与连接刷新。

## 兼容性说明

- 本版本面向 GTNH 2.9 beta 适配；若仍使用旧 GTNH 版本，请优先保留上一稳定版本。
