## 本次更新

- 升级开发依赖基线到 GTNH `2.9.0-beta-1`，同步接入 `gtnhsettingsconvention` `2.0.25`。
- Qz-UILib 升级到 `4.2.0`，开发运行环境改用 `dev` classifier，避免 MCP 命名环境误加载无后缀发布 jar。
- 适配 GTNH 2.9 beta 的 GT / BW / GT++ 普通矿 adapter 掉落入口，恢复高等级时运配置在新矿石 API 下的作用。
- 适配 GTNH 2.9 beta 的 GT 线缆刷新 API，线缆替换继续触发客户端显示、邻居更新和 cable graph 刷新。
- 接入项目级 CodeGraph MCP 配置，便于后续在 opencode 中进行符号和调用关系分析。

## 兼容性说明

- 非必要整合包兼容依赖继续使用 non-publishable 运行配置，不写入 Qz-Miner 发布依赖。
