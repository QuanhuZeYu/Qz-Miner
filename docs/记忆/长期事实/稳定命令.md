# 稳定命令

本文件记录项目可长期复用的构建、检查、测试和运行命令。

## 当前状态

- 当前项目使用 Gradle Wrapper 和 Kotlin DSL 构建脚本。

## 默认候选

- 构建检查：`.\gradlew.bat check`
- 打包：`.\gradlew.bat build`
- 测试：`.\gradlew.bat test`
- 客户端运行：`.\gradlew.bat runClient`
- 服务端运行：`.\gradlew.bat runServer`

## 当前已验证

- 编译：`./gradlew.bat compileJava`

- 只有实际可执行、可复用的命令才能写入。
- 命令或环境前提变化后及时更新本文件。
