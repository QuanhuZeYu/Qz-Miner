# 项目约定

本文件记录项目级、长期有效、且不适合直接塞进 `AGENTS.md` 的具体约定。

## 当前状态

- 缺陷修复优先采用工程级修复：先定位边界与同类风险，再收敛为可复用机制或稳定架构约束，避免只围绕当前堆栈做一次性小补丁。
- GT / BW / GT++ 普通矿的时运上限突破，必须优先拦截上游 `getDrops` 中的 `fortune > 3` 截断，不能只通过重算 `Random.nextInt(...)` 参数实现。
- 相关表达式注入依赖 `MixinExtras`，`mixins.qz_miner.json` 需要保留 `mixinextras.minVersion` 声明。
- GitHub release 标题统一使用 tag 名；`.changelogs/<tag>.md` 只负责 release 正文，不负责标题。
- 已接入 CodeGraph MCP 后，具体类、方法、调用链、依赖图和影响面优先用 `codegraph` 查询缩小范围，再用源码读取和测试确认；详细约定见 `docs/记忆/长期事实/CodeGraph协作.md`。
- 开发依赖基线当前同步到 GTNH `2.9.0-beta-1`、Qz-UILib `4.2.0` 与 `gtnhsettingsconvention` `2.0.25`，非平台硬依赖的整合包兼容依赖默认使用 non-publishable 配置，避免写入发布依赖。
- 外部 1.7.10 mod 进入 RFG dev runtime 时，优先依赖 `dev` classifier 或 Gradle metadata 中的 MCP 变体；Qz-UILib `4.2.0` 当前按 `devOnlyNonPublishable("com.github.QuanhuZeYu:Qz-UILib:4.2.0:dev")` 接入。

## 适合写入本文件的内容

- 项目特有的模块拆分约定。
- 特定错误处理口径。
- 配置文件组织方式。
- 测试目录和命名口径。
- 文档命名和示例维护约定。

## 不适合写入的内容

- 通用 Git 规范、提交规范、语言通用规范。
- 当前任务状态或阶段计划。
- 一次性试验结论。
