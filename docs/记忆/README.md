# AI 协作记忆层

本目录用于在仓库内维护 AI 协作所需的项目记忆，目标是解决两类问题：

- 会话里产生的重要信息不能及时写回项目。
- 单一核心文档越写越长，最终难以维护。

本目录按三层组织：当前态、长期事实、决策记录。

## 目录结构

| 目录/文件 | 作用 | 更新频率 |
|-----------|------|----------|
| [当前态/](当前态/) | 当前阶段目标、当前状态、下一步计划、交接信息 | 高 |
| [长期事实/](长期事实/) | 项目结构、架构边界、稳定命令、长期约定 | 中 |
| [决策/](决策/README.md) | 关键技术取舍、重要边界决策、后续影响 | 中 |

## 读取建议

1. 进入新任务时，先读 `当前态/当前上下文.md`。
2. 需要确认接下来做什么时，读 `当前态/当前计划.md`。
3. 需要恢复中断现场时，读 `当前态/交接记录.md`。
4. 需要确认稳定事实时，读 `长期事实/` 下对应专题。
5. 需要理解“为什么这样做”时，读 `决策/` 和 `docs/开发者文档/`。

## 写回建议

- 当前目标、阻塞、进度变化：更新 `当前态/`。
- 目录结构、命令、边界稳定下来：更新 `长期事实/`。
- 关键方案取舍：新增或更新 `决策/`。
- 不要把上述内容重新堆回 `docs/AI记忆文档.md`。

## 维护原则

- 小文件、单职责、可覆盖。
- 当前态优先覆盖，不按日期堆日志。
- 稳定事实只记录中长期仍然有效的内容。
- 决策记录必须写清背景、选择和影响。
