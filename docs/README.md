# 文档导航

本目录按五条路线组织项目文档，面向不同读者和用途。

## 文档路线

| 路线 | 目录 | 面向 | 说明 |
|------|------|------|------|
| 用户 README | [../README.md](../README.md) | 所有人 | 项目简介、快速开始、环境要求 |
| 外部使用文档 | [使用文档/](使用文档/README.md) | 使用者或接入方 | 公开能力、配置说明、使用方式 |
| AI 协作记忆层 | [记忆/](记忆/README.md) | AI 协作 Agent、维护者 | 当前态、长期事实、决策记录 |
| 内部开发者文档 | [开发者文档/](开发者文档/README.md) | 项目维护者 | 架构方向、审查结论、错误教训 |
| AI 总导航 | [AI记忆文档.md](AI记忆文档.md) | AI 协作 Agent | 进入各类记忆与文档的总入口 |

## 各路线职责边界

- 用户 README：项目第一入口，只放最核心的信息，不堆细节。
- 使用文档：对外公开的接入手册，内容必须与实现一致，不能比实现更乐观。
- AI 协作记忆层：仓库内的工作记忆系统，按“当前态 / 长期事实 / 决策”分层维护。
- 开发者文档：内部协作用，包含技术边界、审查结论和错误教训。
- AI 总导航：只做导航和读取顺序提示，不承担大段事实堆积。

## 写入原则

- 新增对外能力：同步更新 `使用文档/`。
- 当前阶段、计划、交接变化：同步更新 `记忆/当前态/`。
- 稳定结构、命令、边界变化：同步更新 `记忆/长期事实/`。
- 关键方案取舍：同步更新 `记忆/决策/`。
- 新增审查结论：写入 `开发者文档/reviews/`。
- 发现可复现错误：写入 `开发者文档/errors/`。
- AI 导航或读取规则变化：更新 `AI记忆文档.md`。
- 临时调试记录：不沉淀到文档。
