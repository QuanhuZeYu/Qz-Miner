# 文档导航（控制论闭环组织）

本目录只持久化五类文档：设定值、控制律、传感、反馈、诊断。纠偏是检测到误差后的动作机制，规则集中在 `AGENTS.md`，不单设目录。按"需要什么"对号入座，不要把本文件当知识仓库。

> **最高准绳**：根目录 [NORTH_STAR.md](../NORTH_STAR.md) 是连锁挖矿 mod 的中心思想宪章（设定值层锚），凌驾于以下所有文档。任何架构决策、线程模型调整、掉落与生命周期改动都须先与它对照；冲突时按其《修订纪律》登记偏离。

## 读取顺序（控制论）

1. **定目标** → 按改动主题查看 `NORTH_STAR.md` 或设定值层
2. **查执行规范** → 控制律层（命令/构建/发布）
3. **验证产出** → 传感层（Gradle/CI 验证 + 实机验证）
4. **有误差** → 反馈层（交接看未收敛项 / 错误预防查通则）
5. **查系统健康** → 诊断层（技术债 / 项目结构 / 审查报告）

## 写回纪律

权威源为 [AGENTS.md](../AGENTS.md) 反馈层·文档协作，本文件不重复。要点：

- 业务状态/阻断项/待决策事项 → `反馈层/交接.md`；实时 Git 分支/HEAD/工作区 → `git branch --show-current` / `git rev-parse HEAD` / `git status`
- 宪章指针/硬约束/边界现状 → `设定值层/`
- 执行规范（编排/命令/约定/发布）→ `控制律层/`
- 验证边界/测试体系 → `传感层/`
- 错误预防通则/错误详情/决策回写 → `反馈层/`
- 技术债/项目结构/审查报告 → `诊断层/`
- 对外能力变化 → `使用文档/` 与 `开发者文档/`
- 临时调试、一次性试验结论不沉淀
