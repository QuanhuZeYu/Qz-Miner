## 真源优先级

文档之间冲突时按此顺序裁决，上位真源压过下位：

1. **实时源码及其注释** —— 唯一实现真源；行为、契约边界与失败语义写在最近的代码处。
2. **[AGENTS.md](../AGENTS.md)** —— 项目边界、高影响安全边界与工作方式。
3. **[连锁框架指导](../src/main/java/club/heiqi/qz_miner/chain/package-info.java)** —— 本包及其子包共享的权限与真源划分原则：唯一写权威／边界不越权／协作式取消／跨线程只经事件总线／生命周期收口／复用既有入口／显式收尾，每条均标注派生自哪条用户偏好。
4. **根 [README.md](../README.md)** —— 使用者可见的行为、模式与配置的对外说明。
5. **[使用文档/](使用文档/)** —— 配置项语义与 5.3 联机版本边界。
6. **[开发者文档/开放化调整.md](开发者文档/开放化调整.md)** —— 对外稳定边界：哪些是对外入口、哪些只是内部实现。
7. **[反馈层/errors/](反馈层/errors/)** —— 历史踩坑根因与处置结论，本身不构成新的现行规范。

实现细节与一次性施工结论写在最近的代码注释处，不单独立页。
