# 高风险边界导航

本文件只帮助按改动主题定位风险，不是每次修改都必须逐条执行的检查表。总原则见根目录 `NORTH_STAR.md`，具体事实以相关源码、测试、错误记录和决策为准。

| 主题 | 必须守住的结果 | 主要入口 |
|---|---|---|
| 世界与并行 | worker 不写世界；主线程屏障不在 worker 安全停止前放行 | `ParallelTickExecutor`、`ChainExecutionEventBridge` |
| 掉落 | 已收集物品不随会话清理丢失；生成失败可回填 | `ChainPlayerDropBuffer`、掉落错误记录 |
| 网络与生命周期 | 游戏语义状态和 GPU 释放回到对应主线程及统一清理入口 | `ServerMainThreadDispatcher`、`ClientMainThreadDispatcher`、`ChainStateService` |
| 状态机 | `phase`/`generation` 保持单一写权威，不跨玩家串槽 | `ChainStateMachine` |
| 可选模组 | 缺失或链接失败可降级，dedicated server 不加载客户端专属签名 | `ClassNameCompatSupport`、`ReflectiveMemberSupport` |
| GTNH 适配 | 上游升级后复核依赖实现形状的注入点和线缆刷新语义 | 对应 adapter、mixin 与专题决策 |

只有改到相关主题时才沿入口继续阅读。若改动会改变线程主权、玩家资产、协议/持久数据或公共兼容承诺，先取得用户确认。
