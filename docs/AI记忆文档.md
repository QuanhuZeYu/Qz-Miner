# AI 记忆文档

本文件只作为 AI 协作文档总导航。遇到具体任务时，Agent 必须进入对应的分层记忆文件和源码确认现状，而不是只依赖本文件。

## 文档体系导航

| 需要什么 | 去哪里找 |
|----------|----------|
| 文档全局入口 | `docs/README.md` |
| AI 记忆总入口 | `docs/记忆/README.md` |
| 当前阶段、计划、交接 | `docs/记忆/当前态/` |
| 长期稳定事实 | `docs/记忆/长期事实/` |
| 关键技术决策 | `docs/记忆/决策/README.md` |
| 对外使用方式 | `docs/使用文档/README.md` |
| 内部架构方向、审查、错误 | `docs/开发者文档/README.md` |
| 开放化方案与边界 | `docs/开发者文档/开放化调整.md` |
| 审查报告索引 | `docs/开发者文档/reviews/README.md` |
| 错误记录索引 | `docs/开发者文档/errors/README.md` |

## 读取顺序

1. 先读 `docs/记忆/README.md`，确认记忆分层和读取入口。
2. 再按任务类型进入 `当前态/`、`长期事实/`、`决策/`。
3. 涉及对外使用、错误、审查、开放边界时，继续进入对应专题文档。
4. 涉及实现细节时，始终以实际源码和配置为准，不以历史对话推断。

## 主动读取原则

- 涉及当前任务状态、阶段目标、下一步：先读 `docs/记忆/当前态/当前上下文.md` 与 `docs/记忆/当前态/当前计划.md`。
- 涉及交接、恢复现场：先读 `docs/记忆/当前态/交接记录.md`。
- 涉及协作规范、分支管理或提交规则：以根目录 `AGENTS.md` 为准。
- 涉及目录结构、模块边界、运行命令、项目约定：先读 `docs/记忆/长期事实/`。
- 涉及关键设计取舍：先读 `docs/记忆/决策/README.md`。
- 涉及对外使用或接入：读 `docs/使用文档/README.md`。
- 涉及错误复现：读 `docs/开发者文档/errors/README.md`。
- 涉及审查结论：读 `docs/开发者文档/reviews/README.md`。
- 需要具体类、模块、目录位置：用 Glob/Grep/Read 现查，不在本文件维护索引。

## 运行与验证

- Windows 环境，PowerShell。
- 当前项目专属命令请以 `docs/记忆/长期事实/稳定命令.md` 为准。

## 维护边界

- 本文件不再记录阶段流水账、当前计划、模块细节清单和大段项目事实。
- 当前态信息写入 `docs/记忆/当前态/`。
- 长期稳定事实写入 `docs/记忆/长期事实/`。
- 关键方案取舍写入 `docs/记忆/决策/`。
- 本文件只保留总导航、读取顺序和维护边界。

## 本文件的维护规则

- 只记录总导航和读取规则，不承担项目知识仓库角色。
- 有明确归属的信息写回原文档，不在此重复。
- 更新时优先做删减和归并，避免按日期持续追加。
- 临时调试记录和一次性试验结论不沉淀到本文件。
