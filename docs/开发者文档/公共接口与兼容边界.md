# 公共接口与兼容边界

本文件声明 Qz-Miner 对外的稳定边界：哪些可以依赖、哪些明确不稳定、兼容范围与变更处理方式。内部执行算法、内部数据模型与线程安排以源码及其注释为准，不在本文件承诺。

## 可以依赖

- **配置 schema 与 canonical 字符串**
  - 配置路径（`client.*` / `general.*`）、取值域与默认值：见 [使用文档](../使用文档/README.md)；已发布的路径名按兼容承诺处理。
  - `client.objectGroups` 的 `registry@meta` canonical 文本、`LIST<STRING>` schema、selector 语法（`<namespace:path>@*`、`<namespace:path>@<meta>`、`@[集合]`、`ore:<name>`）与已声明的 1024-byte 字符串与条数上限。
- **配置入口**：`config/qz_miner.yaml` 是权威文件；权限等级 `4` 的 `/qzminer config list|get|set|reload` 命令，写范围只覆盖显式 `general.*` scalar 白名单。
- **公开入口与联机规则**：`@Mod` 依赖声明 `required-after:qz_uilib@[4.11.0,5.0.0)`（5.3.5 起；4.11.0 提供环境端口 `ui.env` 与 `ColorSpec` 等公共面，其上是 4.11.x）；上游 4.11.0 的远端范围收紧为 `[4.11.0,4.12.0)`，与 4.10.x 双向不承诺混用，安装包与服务器须把 Qz-UILib 一并升到 4.11.x。版本族的互通规则（**族 = 当前构建版本的 `major.minor`，由制品版本推导，不手写族常量**）与已冻结的 packet/Side、wire/protocol 与 schema 范围，合同见 [使用文档](../使用文档/README.md) 的「联机版本边界」。
- **第三方工具兼容入口**：未声明 Forge harvestTool 的工具按 Minecraft 稳定的 `Item.canHarvestBlock(Block, ItemStack)` 判定。这不是新的 Qz-Miner 适配 API，也不承诺模组类白名单。
- **自动工具换位的 schema 路径**：`client.autoToolSwapEnabled` 与 `client.autoToolPrioritySelectors` 的路径名保持不变；两项的生效值取自**服务器自己的**已提交配置，活动 session 冻结创建时策略，远程客户端值不会写服务器 Authority。
- **模式判定边界**：扩展匹配规则只能作为现有模式的筛选扩展，不得改变顶层模式判定——`CHAIN` 的连通拓扑由规划启动时冻结的可收获能力决定，`AREA`/隧道类按空间或结构范围宽进并逐个交服务端主线程终裁。worker 不得读取实时库存或当前主手，真实破坏资格由服务端主线程逐目标终裁；confirmed/预览只表示「待尝试目标」，规划结果不是执行授权。

## 明确不稳定（不构成 API）

- `club.heiqi.qz_miner.objectgroup` 下的 selector / parser / domain / snapshot 是配置与运行时内部模型：只承诺 `registry@meta` canonical 字符串与 `LIST<STRING>` schema，不承诺 Java 类型、方法或容器形态；旧 `metadataMask/fromMask` 已删除，不提供反向兼容壳。
- 自动工具换位的 wire（内部协议 v4 五包）及其 packet ID、字段布局、动作码、固定 framing、round 状态与 `actionSequence`：是**当前 minor 族内部**的客户端/服务端原子版本边界，外部不应依赖；跨 minor 的更旧端在版本校验处 fail-closed，不提供跨 minor fallback 或 source compatibility 壳。
- 内部服务与写入口：服务端库存换位与发布路径、round 服务、客户端 reducer、packet callback 都不是第三方库存事务 API；外部不得把它们当作第二库存写入口，客户端也不得自行写库存或通过容器点击模拟。
- 内部实现细节（类名、内部端口、线程池参数、算法阶段与线程安排）一律以源码及其注释为准，不进本文件。

## 兼容范围与变更处理

- **同一 minor 族（`major.minor`）内**忽略 patch、prerelease 与 build qualifier 互通；不兼容变更必须升新 minor。族取自制品版本、由握手策略推导——写死族会在制品跨出该 minor 时让双方互相拒绝。
- 「可以依赖」各项的变更属于对外变更，需同步更新文档与使用说明；「明确不稳定」各项的调整不视为对外变更。
- 本文档只描述对外边界，不描述内部执行机制。实现与本文档不一致时应指出偏差并核实原因：**不能仅因代码已如此实现就视为契约已变更**；确需变更对外承诺时，按上一节「可以依赖」的变更处理规则同步更新本文档。

## 维护规则

- 只记录长期有效的对外边界；临时试验与施工过程不沉淀。
- 内部算法与实现细节写在最近的源码注释处。
