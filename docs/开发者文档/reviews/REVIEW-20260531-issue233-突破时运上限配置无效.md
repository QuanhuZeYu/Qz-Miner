# Review: issue233 突破时运上限配置无效

## 范围

- GitHub issue `#233`
- GT / BW / GT++ 普通矿的时运上限突破配置

## 主要发现

- 当前实现只重定向了 `Random.nextInt(...)`，没有覆盖上游在 `getDrops` 中先执行的 `fortune > 3` 截断。
- `enableUnlimitedOreFortune` 的配置文案承诺“解除 3 级时运上限”，但旧实现无法兑现该语义。
- 仓库内缺少覆盖 `fortune > 3` 场景的回归测试，只能依赖编译与运行验证。

## 审查结论

- issue 结论成立，属于真实缺陷，不是误报。
- 修复方向应落在 `fortune > 3` 表达式拦截，而不是继续重算 `nextInt` 参数。

## 后续动作

- 已改为使用 `MixinExtras @ModifyExpressionValue` 拦截 GT / BW / GT++ 三处 `fortune > 3` 判断。
- 已在 `mixins.qz_miner.json` 中声明 `mixinextras.minVersion = 0.5.0`。
