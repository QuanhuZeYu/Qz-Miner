# 开发者文档

本目录面向项目维护者和 AI 协作 Agent，记录内部架构方向、专项审查结论、错误教训和开放化边界。

> 本区所有文档视为内部开发资料，不面向外部接入方。对外说明见 [使用文档](../使用文档/README.md)。

## 目录结构

| 文件/目录 | 说明 |
|-----------|------|
| [开放化调整.md](开放化调整.md) | 从内部实现到对外入口的开放化边界 |
| [reviews/](reviews/README.md) | 审查报告索引与详细报告 |
| [errors/](errors/README.md) | 错误记录索引与详细问题分析 |

> 当前任务状态、长期稳定事实和决策记录已拆分到 `docs/记忆/`，避免核心文档继续膨胀。

## 文档写入规则

- 审查结论：写入 `reviews/REVIEW-YYYYMMDD-主题.md`，并在 `reviews/README.md` 添加索引条目。
- 可复现错误：写入 `errors/ERROR-YYYYMMDD-简述.md`，并在 `errors/README.md` 添加索引条目。
- 对外入口、兼容边界或开放策略变化：更新 `开放化调整.md`。
- 当前态、稳定事实、决策记录：写入 `docs/记忆/` 对应层级，而不是塞进本目录总览。

## 与其他文档区的关系

- 本区记录“为什么这样做”和“踩过什么坑”。
- `docs/记忆/` 记录“当前在做什么”“项目稳定事实是什么”“关键决定是什么”。
- `docs/使用文档/` 记录“怎么用”。
- `docs/AI记忆文档.md` 只保留总导航与读取顺序。
- 根目录 `README.md` 面向首次访问者。
