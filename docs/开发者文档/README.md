# 开发者文档

本目录是**产品输出区**，记录从内部实现到对外入口的开放化边界。不参与控制论分层。

> 内部协作文档（当前态/决策/错误/审查/技术债/稳定事实）已按控制论五层归位到 `docs/{设定值层,控制律层,传感层,反馈层,诊断层}`，见 [docs/README.md](../README.md)。本目录只留对外开放边界类资料。

## 目录结构

| 文件 | 说明 |
|------|------|
| [开放化调整.md](开放化调整.md) | 从内部实现到对外入口的开放化边界 |

## 与控制论分层的关系

- 对外入口、兼容边界或开放策略变化：更新本目录 `开放化调整.md`
- 对外使用方式：见 [使用文档](../使用文档/README.md)
- 内部架构方向、审查、错误、技术债：归控制论分层（设定值/控制律/传感/反馈/诊断）
