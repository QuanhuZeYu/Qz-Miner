# 开发者文档

本目录是产品输出区：只放对外入口与兼容边界类资料，面向需要在外部依赖 Qz-Miner 的接入方。

## 目录结构

| 文件 | 说明 |
|------|------|
| [公共接口与兼容边界.md](公共接口与兼容边界.md) | 对外稳定边界：可依赖项、明确不稳定项、兼容范围与变更处理 |

## 维护边界

- 对外入口、兼容边界或开放策略变化：更新 `公共接口与兼容边界.md`
- 对外使用方式：见 [使用文档](../使用文档/README.md)；文档分区与职责总览见 [docs/README.md](../README.md)
- 内部架构方向、设计意图与失败语义：写在最近的源码注释处（协作规范见 [AGENTS.md](../../AGENTS.md)）
- 内部错误与踩坑：归 [反馈层/errors/](../反馈层/errors/)
- 实现细节（类名、内部端口、线程池参数、施工经过）不进本目录，以源码及其注释为准
