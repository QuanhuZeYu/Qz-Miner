# 开放化调整

本文件记录从内部实现到对外入口的开放边界。

## 当前状态

- 自动工具换位的 Qz-Miner round/intent/result/phase 协议是内部客户端/服务端原子版本边界，不是可混版本调用的公共 API。客户端与服务端必须使用同一 Qz-Miner 版本；外部接入方不应依赖包 ID、字段布局、round 状态或 sequence 细节。
- 自动工具协议只承载换位请求、结算和连锁阶段关联，不替代原版库存同步。库存交换由服务端主线程应用，客户端库存视图仍以服务端原版容器差异同步为准；客户端不应自行写库存或通过原版容器点击模拟该事务。

## 适合写入本文件的内容

- 对外配置入口开放范围。
- 兼容开关暴露策略。
- 内部实现迁出为公开接口的边界。
- 外部接入方依赖的稳定约束。

## 维护规则

- 只记录长期有效边界。
- 临时试验不沉淀。
