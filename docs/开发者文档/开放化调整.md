# 开放化调整

本文件记录从内部实现到对外入口的开放边界。

## 当前状态

- 自动工具换位的 Qz-Miner 协议 v3（round/intent/result/phase/takeover target）是内部客户端/服务端原子版本边界，不是可混版本调用的公共 API。v2 及更旧端在版本校验处 fail-closed；外部接入方不应依赖包 ID、字段布局、round 状态或 sequence 细节。
- 自动工具协议只承载换位请求、结算、连锁阶段关联和服务端目标请求，不替代原版库存同步。中途接替保持同一 `serverRoundId`；客户端在下一 ClientTick 选候选，服务端重验后执行双槽交换或单次三槽引用轮转。客户端不应自行写库存或通过原版容器点击模拟该事务。
- planner 的 confirmed/preview 是预算化世界/几何/结构候选，不是工具能力承诺；扩展 matcher 不应在 worker 读取实时库存、当前工具或调用未知 Item 回调。真实破坏资格与 `tryHarvestBlock` 结果由服务端主线程逐目标终裁。
- 未声明 Forge harvestTool 的工具兼容入口是 Minecraft 稳定 `Item.canHarvestBlock(Block, ItemStack)`；这不是新的 Qz-Miner 公共适配 API，也不承诺模组类白名单。候选硬门为 canHarvest 与耐久储备，效率只是事实。

## 适合写入本文件的内容

- 对外配置入口开放范围。
- 兼容开关暴露策略。
- 内部实现迁出为公开接口的边界。
- 外部接入方依赖的稳定约束。

## 维护规则

- 只记录长期有效边界。
- 临时试验不沉淀。
