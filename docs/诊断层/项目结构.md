# 项目结构

> **职责约定**：本文件是项目结构地图，只陈述当前真实存在的目录与类。「已删除/曾经/迁移前/旧」类历史叙事归 `docs/反馈层/决策/` 或 `docs/反馈层/errors/`。引用的类名/路径必须真实存在于 src 下（由 `scripts/check-doc-fact-drift.ps1` 守卫，地图失真即阻断合并）。

## 目录范围

- `src/main/java/club/heiqi/qz_miner/`：模组主代码。
- `src/main/resources/`：资源与配置。
- `docs/`：文档总目录（控制论五层 + 产品输出区）。
- `docs/{设定值层,控制律层,传感层,反馈层,诊断层}/`：控制论五层协作文档。
- `docs/{使用文档,开发者文档}/`：产品输出区。
