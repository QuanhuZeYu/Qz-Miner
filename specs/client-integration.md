# 客户端接入

## 能力范围

6.0 通过 UILib 5.0 正式通用设置模板、Scene 控件与 Minecraft HUD 宿主提供配置 GUI、对象组编辑和状态 HUD；YAML、服务端命令、对象组业务及世界预览 shader 沿原合同。通用框架只归 UILib，Miner 提供业务草稿、权限、提交与状态投影。业务页面与 HUD 统一使用 SceneAppearance 的角色、字体和动态主题；分组短说明归资源文案，技术配置注释只服务持久化文档。

配置页经 Forge 配置工厂和可绑定客户端按键打开，主菜单也可进入；按挖矿、预览与 HUD、对象组、服务端规则组织，复用 schema 类型和校验。对象组以组 ID、模式和有序成员编辑，合法但未注册的 selector 保留原文本，不从启动时注册表快照限制候选。配置来源、权限与保存基线归[配置合同](<configuration.md>)；关闭有改动时提供保存、放弃和继续编辑选择。后台保存完成只通知仍存活且生命周期未变更的页面，迟到完成不得改写新页面的草稿。草稿上下文失效后仍可明确放弃离开，页面不因旧 busy 等待封死导航，已进入原子事务的保存不额外回滚。

HUD 闲时完全隐藏；按连锁键、模式切换及任务阶段变化时唤出，任务或远端请求活动时保持可见，结束结果短留后收起。离散变化刷新短留，计数和采样进度不延长期限，历史超时/不可用原因不得永久占屏。操作时使用精密环形表盘：中央显示当前主/子模式，上下显示前后子模式，左右显示可用相邻主模式；主模式横向、子模式纵向过渡，环刻度有限转动，松键后邻项收拢为当前模式和紧凑状态。连锁青、爆破金、交互绿、特殊紫随主题明暗适配，模式身份与状态告警独立，识别不只依赖颜色；刻度区自带完整不透明底衬，方位、主次和细刻度以长度、粗细和墨色分级，不依赖游戏画面提供对比。压边、刻度凹槽、内盘与中央读数窗形成材质层级，中央模式、邻项、状态和明细依次降低视觉权重；环线不代表任务进度。确认中和远端失败显式标示；预览和服务端确认分别标明，本机采样进度仅称估算，不冒充权威完成量，后端诊断按原开关展示。HUD 订阅已有表现/阶段投影，变化时更新展示，不每帧遍历目标。出场以环线扫入、刻度点亮、中央与四向邻项展开及状态明细错峰显现表达层次，静止后停止装饰运动；主模式须尽早可读，动效不延迟业务操作。展开、模式和状态变化沿 Core 正式声明式动效并服从关闭/减少策略。位置编辑保持完整 HUD 可见，沿 UILib 拖动、吸附、内容缩放与默认恢复，画布以完整 framebuffer 视口解释锚点和像素偏移；Minecraft GUI Scale 不改变 HUD 尺寸、文字大小、偏移或吸附；可收起工具层不改变位置参考，预览复用实际 HUD 内容。正常 HUD 不消费输入。

## 输入与预览

- 连锁键与潜行键取游戏当前绑定；按住连锁键滚轮切子模式，叠加潜行切主模式，各主模式记忆子模式。该组合独占滚轮；未按连锁键或打开 GUI 时保留原版滚轮行为。
- 预览只读并投影待尝试目标，不写世界、不阻塞服务端执行；执行轮次冻结的目标与空间锚点保持一致，远端结果仅在对应连接、世界和请求仍有效时采纳。
- 预览受用户配置、服务端规模限制与本机硬上限共同约束；同坐标只占一次几何配额。缓存有界且随配置、世界、资源与渲染依赖变化失效，关闭预览后不继续计算目标。
- 深度显示新增“可见不透明”档：露出部分在稳态不透明，遮挡部分保留原距离透明度；两者均保留原生长及淡入淡出过渡、颜色和规模限制。遮挡以当前场景深度为准，预览不写深度；不写场景深度的半透明表面不作为遮挡。原有透视、遮挡与描边档及默认选择保持原语义。
- 保留 shader 与 legacy 后端；能力不足或 shader 失败按既有策略回退并给出有限诊断，不每帧重试。GL 状态用后恢复，shader、buffer 等 GPU 资源在渲染主线程创建与释放。

## 生命周期与可选能力

网络入包先做有界解码，再回对应主线程复核真实连接与世界身份，才发布客户端投影；旧响应、重复连接事件与迟到清理不得接管或清除新会话。断线、世界卸载与重载经统一入口停止预览、清 pending、解除订阅并释放所属 GPU 资源，重复清理安全。服务端半径/数量确认属于连接，保留于同 handler 世界替换，断线/连接接管及本机 fallback 初始化时失效，不把本机 fallback 显示为已确认。

可选 Mod 仅在能力可靠可用时注册和运行，失败安全降级；能力或注册表变化发布代际，HUD 相邻模式投影据此失效，刷新不伪造导航输入或改变业务选中值。探测不得触发不必要的静态初始化。公共入口与 dedicated server 加载路径不含客户端专属签名或静态链接。

## 验收

- 连续输入、GUI 开关、配置变化和连接/世界替换不遗留旧预览或抢滚轮；对象组在无 GUI 时仍可经 YAML 生效。
- shader 离线编译与降级路径分别验证；真实 GL 状态恢复、资源重载、退出重入与可选 Mod 缺失另以游戏运行证据验收，离线编译不代替实机。
