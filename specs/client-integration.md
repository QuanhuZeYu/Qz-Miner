# 客户端接入

## 能力范围

6.0 通过 UILib 5.0 正式通用设置模板、Scene 控件与 Minecraft HUD 宿主提供配置 GUI、对象组编辑和状态 HUD；YAML、服务端命令、对象组业务及世界预览 shader 沿原合同。通用框架只归 UILib，Miner 提供业务草稿、权限、提交与状态投影。

配置页按挖矿、预览与 HUD、对象组、服务端规则组织，复用 schema 类型和校验；对象组以组 ID、模式和成员编辑，合法但未注册的 selector 保留原文本，不从启动时注册表快照限制候选。远端服务端规则及服务端控制的自动工具项只读，明确显示来源；本机单人世界的管理字段遵循管理资格。保存通过已有全量原子提交，失败保留草稿，关闭有改动时提供明确选择。

HUD 平时紧凑显示当前模式、子模式与状态；按连锁键或任务活动时展开范围、数量及有关预览信息，确认中和远端失败显式标示。预览和服务端确认分别标明，本机采样进度仅称估算，不冒充权威完成量；后端诊断按原开关展示。HUD 订阅已有表现/阶段投影，变化时更新展示，不每帧遍历目标。位置编辑沿 UILib 拖动、吸附、缩放与默认恢复，保存锚点和逻辑偏移；正常 HUD 不消费输入。

## 输入与预览

- 连锁键与潜行键取游戏当前绑定；按住连锁键滚轮切子模式，叠加潜行切主模式，各主模式记忆子模式。该组合独占滚轮；未按连锁键或打开 GUI 时保留原版滚轮行为。
- 预览只读并投影待尝试目标，不写世界、不阻塞服务端执行；执行轮次冻结的目标与空间锚点保持一致，远端结果仅在对应连接、世界和请求仍有效时采纳。
- 预览受用户配置、服务端规模限制与本机硬上限共同约束；同坐标只占一次几何配额。缓存有界且随配置、世界、资源与渲染依赖变化失效，关闭预览后不继续计算目标。
- 保留 shader 与 legacy 后端；能力不足或 shader 失败按既有策略回退并给出有限诊断，不每帧重试。GL 状态用后恢复，shader、buffer 等 GPU 资源在渲染主线程创建与释放。

## 生命周期与可选能力

网络入包先做有界解码，再回对应主线程复核真实连接与世界身份，才发布客户端投影；旧响应、重复连接事件与迟到清理不得接管或清除新会话。断线、世界卸载与重载经统一入口停止预览、清 pending、解除订阅并释放所属 GPU 资源，重复清理安全。

可选 Mod 仅在能力可靠可用时注册和运行，失败安全降级；探测不得触发不必要的静态初始化。公共入口与 dedicated server 加载路径不含客户端专属签名或静态链接。

## 验收

- 连续输入、GUI 开关、配置变化和连接/世界替换不遗留旧预览或抢滚轮；对象组在无 GUI 时仍可经 YAML 生效。
- shader 离线编译与降级路径分别验证；真实 GL 状态恢复、资源重载、退出重入与可选 Mod 缺失另以游戏运行证据验收，离线编译不代替实机。
