# 挖矿与生命周期

## 权威与执行

- 服务端状态机是 phase/generation 唯一写权威；客户端只持投影。跨线程结果按玩家、连接、世界与任务身份复核后在所属主线程消费；旧入包、旧完成或清理不能改变新会话。
- 方块破坏、正常右键、库存事务、掉落实体生成与世界状态修改只在服务端主线程。worker 只读世界和启动时冻结的能力，不读实时库存或当前主手，只发布不可变规划结果。
- CHAIN 以冻结的可收获能力形成连通拓扑；AREA 与 INTERACT 按空间/结构范围收集待尝试目标，精确空气不扩展连锁。对象组只扩展既有匹配，不改变顶层模式或授权边界。
- 规划、confirmed 与预览都不是执行授权。每目标执行前重验区块、当前身份、工具、编辑权限、保护与 Forge event；单目标漂移、拒绝、无动作或异常只结算该目标。
- INTERACT 复用正常方块/物品右键语义；液体源由当前物品自行处理，不直接 drain 或伪造容器；作物成熟度未知时不得按未成熟施肥。GT 线缆替换预检后保持单 tick 原子执行。

## 停止与收口

- Tick 预算是安全点观察的 soft deadline；已开始事务完成后再让出。取消、超时与预算耗尽协作停止，必须经过 `ParallelTickExecutor.endStage(...)` 等待 worker 到安全边界，不以 `Future.cancel(true)`、强杀或跳过屏障制造半完成状态。
- 成功创建执行 context 才打开执行窗口；未进入执行的取消不得留下窗口。完成、取消、异常、登出、重生、克隆、切维度与服务停止统一收尾，运行态、订阅与缓存可释放；重入不重复结算。
- 连锁键表达持续授权，观测事件表达单次动作；收尾后按仍有效的电平再武装，不要求玩家松键才能开启下一轮。
- 普通 CHAIN/AREA 的工具换位由服务端唯一库存事务入口管理；每目标按当前手与候选能力决定，低耐久或无候选只跳当前目标，创造模式、INTERACT 与线缆 SPECIAL 不换位。未声明 harvestTool 的工具复用 `Item.canHarvestBlock`。
- 收尾先恢复借用工具或明确归类库存冲突，再清执行状态；不覆盖第三方改写，不伪报恢复成功，客户端不自行写库存或模拟容器点击。

## 掉落资产

已收集掉落归玩家，独立于运行态生命周期。生成失败、返回拒绝、异常、玩家离线或缺少释放上下文时保留或回填未释放资产，之后仍能领取；会话移除、失败次数或诊断限流都不是丢弃理由。已成功生成的部分不得再次生成，不得以清空缓冲掩盖失败。服务停止后的残留缓冲仅留本进程，退出 JVM 不保证恢复；不自动投放到后续存档。权限等级 `4` 可用 `/qzminer drops recover <player>` 将该玩家的停止资产显式释放到其当前位置，失败部分保留。

## 验收

- 安全点暂停/恢复、预算耗尽、取消和 watchdog 都保持屏障与事务完整；无 context 的提前取消不永久开窗，按住键可连续触发。
- 目标或权限在规划后变化时逐目标重验；库存冲突、工具耗尽与模式切换不造成额外写入或半恢复状态。
- 模拟部分生成、持续失败及生命周期切换：成功部分只生成一次，失败资产仍归原玩家且可领取；旧端点消息不清新会话。
