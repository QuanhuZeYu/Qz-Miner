# Qz-Miner 重构需求文档

## 1. 项目概述
- **项目名称**：Qz-Miner（爆破连锁）
- **目标平台**：Minecraft 1.7.10 + GTNH（GregTech New Horizons）
- **项目类型**：智能连锁挖矿模组
- **当前状态**：4.0版本重构，采用vibecoding形式重构以优化项目结构

## 2. 核心功能需求

### 2.1 三主模式架构
#### 连锁模式（Chain Mode）
- **基础连锁模式**：智能邻块检测，增强型3D范围检测（可配置）
- **精准匹配**：支持方块meta值和掉落物damage校验
- **功能**：基于中心方块的连锁挖掘

#### 爆破模式（Range Mode）
- **无差别爆破模式**：范围内所有方块的暴力清除
- **筛选爆破模式**：按条件筛选方块进行爆破
- **隧道爆破模式**：隧道挖掘功能
- **矿石爆破模式**：矿脉识别与清除
- **爆破伐木模式**：树木砍伐功能

#### 交互模式（Interact Mode）
- **基础连锁模式**：通过右键方块触发连锁
- **筛选爆破模式**：右键触发的筛选爆破
- **流体搜索模式**：流体检测功能
- **作物搜索器**：作物收割功能

### 2.2 特色功能需求
- **智能农作**：右键成熟作物自动收割（保留作物本体）
- **视觉辅助**：实时渲染挖掘区域预览
- **异步线程管理**：避免主线程卡顿
- **智能缓存机制**：解决内存泄漏问题
- **时运限制解除**：突破时运III上限

## 3. 技术需求

### 3.1 开发环境
- **Minecraft版本**：1.7.10
- **Forge版本**：10.13.4.1614
- **Java版本**：支持现代Java语法（通过Jabel）
- **构建工具**：Gradle（GTNH Convention插件）

### 3.2 依赖管理
- **GT5-Unofficial**：5.09.51.482（主要依赖）
- **ServerUtilities**：2.2.2
- **NotEnoughItems**：2.8.44-GTNH
- **Applied-Energistics-2**：rv3-beta-695-GTNH
- **AppleCore**：3.3.7
- **JOML**：1.10.8（数学库）
- **qz_uilib**：4.1.1-LTS（JitPack：`com.github.QuanhuZeYu:Qz-UILib:4.1.1-LTS`）

### 3.3 配置需求
- **最大连锁半径**：可配置（默认8）
- **最大连锁数量**：可配置（默认1024）
- **小区域检测半径**：可配置（默认2）
- **隧道半径**：可配置（默认1）
- **客户端配置**：预览功能、消息提示、饥饿值消耗

## 4. 架构需求

### 4.1 模块化设计
