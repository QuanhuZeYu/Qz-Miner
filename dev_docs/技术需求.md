# Qz-Miner 技术需求文档

## 1. 技术栈

### 1.1 基础环境
- **Minecraft**: 1.7.10
- **Forge**: 10.13.4.1614
- **Java**: 8+（通过Jabel支持现代语法）
- **构建工具**: Gradle 8.0.1（GTNH Convention插件）

### 1.2 核心依赖
```gradle
// 主要依赖
implementation("com.github.GTNewHorizons:GT5-Unofficial:5.09.51.482:dev")
implementation('org.joml:joml:1.10.8')
implementation("com.github.QuanhuZeYu:Qz-UILib:4.1.1-LTS") { transitive = false }

// 运行时依赖
runtimeOnly("com.github.GTNewHorizons:ServerUtilities:2.2.2:dev")
runtimeOnly("com.github.GTNewHorizons:NotEnoughItems:2.8.44-GTNH:dev")
runtimeOnly("com.github.GTNewHorizons:Applied-Energistics-2-Unofficial:rv3-beta-695-GTNH:dev")
runtimeOnly("com.github.GTNewHorizons:AppleCore:3.3.7:dev")
```

### 1.3 开发工具
- **IDE**: IntelliJ IDEA（推荐）
- **代码格式化**: Spotless（可选）
- **代码检查**: Checkstyle（可选）
- **Mixin支持**: 启用Mixin调试

## 2. 架构设计

### 2.1 模块划分
```
src/main/java/club/heiqi/qz_miner/
├── core/                    # 核心逻辑模块
│   ├── founder/            # 搜索算法实现
│   ├── BaseOperator.java   # 基础操作器
│   ├── InteractOperator.java # 交互操作器
│   ├── Manager.java        # 玩家管理器
│   ├── MinerConfig.java    # 配置类
│   ├── MinerModeState.java # 模式状态管理
│   └── PlayerManager.java  # 玩家管理器
├── client/                  # 客户端模块
│   ├── KeyListener.java    # 键盘监听
│   ├── PreviewRender/      # 预览渲染
│   └── configGUI/          # 配置界面
├── network/                 # 网络通信模块
│   ├── NetworkMain.java    # 网络主类
│   └── Packet*.java        # 各种数据包
├── thread/                  # 多线程模块
│   └── ParallelTick.java   # 并行tick处理
├── utils/                   # 工具类
├── mixins/                  # Mixin修改
├── Config.java             # 配置管理
├── Constant.java           # 常量定义
├── MyMod.java              # 模组主类
├── ClientProxy.java        # 客户端代理
└── CommonProxy.java        # 通用代理
```

### 2.2 核心类职责
- **MyMod**: 模组入口，事件转发
- **PlayerManager**: 管理所有玩家的连锁状态
- **Manager**: 单个玩家的连锁管理器
- **BaseOperator**: 连锁操作执行器
- **MinerModeState**: 模式状态管理
- **BasePositionFounder**: 搜索算法基类

## 3. 配置系统

### 3.1 配置参数
```java
// 全局配置
int bigRadius = 8;          // 最大连锁半径
int blockLimit = 1024;      // 最大连锁数量
int smallRadius = 2;        // 小区域检测半径
int tunnelWidth = 1;        // 隧道半径

// 客户端配置
boolean usePreview = true;  // 使用预览功能
boolean useChainDoneMessage = true; // 使用完成消息
double addExhaustion = 0.025; // 每次挖掘增加的饥饿值
```

### 3.2 配置加载
- 使用Forge的Configuration系统
- 支持运行时配置更新
- 客户端和服务端配置分离

## 4. 网络通信

### 4.1 数据包类型
- **PacketChainSwitcher**: 连锁开关同步
- **PacketMinerConfig**: 配置同步
- **PacketMinerModeState**: 模式状态同步

### 4.2 通信协议
- 客户端→服务端：连锁开关、配置更新
- 服务端→客户端：模式状态、错误消息
- 使用FML的网络系统

## 5. 多线程设计

### 5.1 线程模型
- **主线程**: 游戏逻辑、事件处理
- **搜索线程**: 搜索算法执行（可中断）
- **渲染线程**: 客户端预览渲染

### 5.2 线程安全
- 使用LinkedBlockingQueue进行线程间通信
- 原子变量控制状态
- 可中断的搜索算法

## 6. 性能优化

### 6.1 搜索算法优化
- 使用BFS/DFS进行位置搜索
- 限制每tick处理数量（默认64）
- 智能缓存避免重复计算

### 6.2 内存管理
- 及时清理搜索结果
- 使用对象池（可选）
- 避免内存泄漏

## 7. 兼容性设计

### 7.1 版本兼容
- 支持GTNH 2.8.4及后续版本
- 向后兼容旧版本配置

### 7.2 模组兼容
